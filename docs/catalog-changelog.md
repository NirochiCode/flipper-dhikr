## v1.0

- First release in the Flipper Apps Catalog. This catalog version 1.0 corresponds to the GitHub release v1.0.3.
- Tasbih counter with targets 33, 99 or a custom value from 1 to 9999 per profile
- Automatic restart at the target with "Target reached!" and a count of completed sets
- Undo by holding Down, including restoring a set directly after it was completed
- Built-in and custom Dhikr profiles with a details menu: View Progress, Edit Target, Reset Progress, Rename and Delete
- Reset Progress for exactly the chosen profile, with a confirmation dialog
- Independent vibration and sound switches for counting and for the target
- Crash-safe storage on the SD card with automatic migration of older data
- New crescent and star app icon
